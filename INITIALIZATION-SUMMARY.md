## Key Decisions Made

### 1. **Architecture - Pure Static Site**
- No build process required
- No dependencies beyond metadata in package.json
- HTML5 + CSS3 + Vanilla JavaScript only
- Served as-is from repository

### 2. **Accessibility & Responsiveness**
- WCAG AA compliance baseline in CSS
- Mobile-first responsive design structure
- Semantic HTML5 structure
- Placeholders for alt text and heading hierarchy

### 3. **Documentation First**
- Comprehensive README.md with all project context
- CLAUDE.md with 7 critical rules to protect project scope, client info, and code quality
- Clear TBD items marked (logo, domain, hosting, photography)

### 4. **Security & Secrets Management**
- .gitignore configured to prevent:
  - Environment variables (.env, .env.local)
  - IDE/OS files (.vscode, .DS_Store, Thumbs.db)
  - Build artifacts and logs
  - Node modules (if future dependencies added)

### 5. **Minimal & Clean Codebase**
- No frameworks or unnecessary dependencies
- Clear placeholder comments for future content
- Organized asset directories ready for content
- No hardcoded business logic, secrets, or assumptions
